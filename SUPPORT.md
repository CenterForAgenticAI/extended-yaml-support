# Support

Use [GitHub Issues](https://github.com/CenterForAgenticAI/extended-yaml-support/issues) for reproducible bugs and feature requests.

For a bug, include:

- Visual Studio Code version
- Extension version
- Operating system
- The smallest YAML example that reproduces the behavior
- Whether decorations, syntax highlighting, or both are affected
- Relevant settings under `extendedYaml.decorations`
- Other installed YAML or theme extensions that may affect highlighting

Do not include credentials, proprietary prompts, or other sensitive YAML content. Replace sensitive values while preserving indentation and tags.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
