# Changelog

All notable changes to Extended YAML Support are documented here.

## 0.1.0

- Add embedded-language highlighting for nine language families and their tag aliases.
- Add configurable block, XML-style tag, and XML-style content decorations.
- Support YAML scalar indentation and chomping indicators in either valid order.
- Add automated formatting, linting, type checking, tests, package inspection, and release publishing.
